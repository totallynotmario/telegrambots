# telegrambots

A curated collection of hand-made Telegram bots, built as small, focused projects. Each bot lives in its own folder with its source code and a set of screenshots showing the main menu, commands, and example responses.

# What’s inside

* Python Mentor
* A lightweight “study buddy” bot aimed at helping with Python learning through quick prompts, guidance, and useful tips.
* Daily Water Goal Bot
* A simple wellness bot that helps you set a daily water intake goal and stay consistent by tracking progress through Telegram.
* Exchange Rates Bot
* A utility bot for checking currency exchange rates on demand, returning clean and readable results directly in chat.

# Repository structure

* One folder per bot (source + assets)
* screenshots/ (or similar) included per bot folder to demonstrate the bot’s UI/outputs

# Notes

These bots are intentionally kept modular and easy to navigate, making the repository suitable both as a personal toolkit and as a reference for building Telegram bots in the same style.
